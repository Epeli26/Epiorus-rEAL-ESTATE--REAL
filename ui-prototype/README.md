# UI prototype

This folder is an isolated design exploration. It is not imported by `src/main.tsx`, so it does not change the current website and is not included in the normal Vite build.

Open `index.html` directly in a browser to preview it. The prototype includes its own local property data, translations, and copied photo assets under `data/` and `assets/`, so property cards, details, galleries, filters, and the lightbox work without the parent `src/` or `public/` folders.
